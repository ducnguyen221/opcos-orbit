Tính năng

Điều phối nhiều agent, nhìn một chỗ là biết hết

Không còn mở 5 cửa sổ terminal để đoán xem con nào đang chạy, con nào đang treo chờ duyệt. OpcOS Orbit gộp tất cả vào một console.

Một Lead, nhiều agent con

Nói hoặc gõ một yêu cầu — Lead (Claude) đọc, phát marker [DELEGATE] giao việc cho Codex/Gemini/Antigravity/Ollama, rồi tự tổng hợp câu trả lời cuối. Bạn chỉ nói chuyện với một "người", việc bên trong tự chia.

Claude · Codex · Gemini · Antigravity · Ollama

Mission Control — dashboard realtime

Mỗi job agent là một thẻ: đang bận, đang chờ bạn duyệt (viền đỏ nhấp nháy nhẹ, kèm gợi ý "im lặng bao lâu"), hoặc đã xong. Thông báo trình duyệt khi có agent cần chú ý — nhưng chỉ khi bạn không đang nhìn tab đó.

blocked · working · done · kill / seen tại chỗ

Voice hai chiều, tuỳ chọn

Giữ nút mic để nói, agent đọc trả lời bằng giọng riêng cho từng vai. Không cấu hình voice thì console vẫn chạy đầy đủ ở dạng gõ chữ.

System pane

Nếu máy có cài opcos, panel System hiện luôn danh sách MCP server đã đăng ký + bản đồ công cụ — không cần rời console để tra.

Session + context

Nhiều phiên hội thoại song song (tab, đổi tên, tắt/resume), gắn file/folder làm ngữ cảnh cho một instance cụ thể.

Điều phối, không phải hộp đen

Orbit không phải một model mới — nó gọi CLI bạn đã cài (claude, codex, gemini…) bằng chính tài khoản đã đăng nhập trên máy bạn. App không giữ, không đọc, không gửi bất kỳ API key nào — dữ liệu đi tới đâu là theo chính sách của CLI đó. Riêng STT/TTS và engine Ollama chạy hoàn toàn cục bộ.

App không giữ API key STT/TTS · trên máy Ollama · trên máy Claude/Codex/Gemini · theo chính sách của họ
Cách hoạt động

Từ một câu nói tới câu trả lời tổng hợp

Lead luôn là người quyết định giao việc cho ai; console chỉ lo phần điều phối, theo dõi và hiển thị.

01

Nói / gõ

Giữ mic hoặc gõ thẳng vào ô chat.

02

Lead đọc & phân việc

Phát marker [DELEGATE] cho 1 hoặc nhiều agent.

03

Spawn CLI headless

Mỗi agent chạy trong tiến trình riêng, stream output sống.

04

Mission Control theo dõi

Máy trạng thái phát hiện blocked/working/done, báo khi cần chú ý.

05

Tổng hợp & trả lời

Lead gộp kết quả, đọc bằng giọng (nếu bật) và hiện transcript.

Cài đặt

Chạy được sau vài dòng lệnh

Clone repo, chạy script cài một lần, rồi khởi động. Chỉ cần các CLI agent bạn muốn dùng đã cài + đăng nhập sẵn trên máy — voice là tuỳ chọn.

  • Windows và Python 3.11+
  • Ít nhất 1 CLI agent đã cài + đăng nhập: claude, codex, gemini…
  • Tuỳ chọn: GPU NVIDIA cho voice realtime (faster-whisper)

Riêng tư & minh bạch

Bạn tự quyết dữ liệu đi đâu

Orbit là lớp điều phối, không phải nơi lưu key hay chặn dữ liệu của bạn. So sánh nhanh với cách làm thủ công thường thấy.

OpcOS Orbit Nhiều cửa sổ terminal thủ công
Biết agent nào đang chờ duyệt Thấy ngay, viền đỏ + thông báo Phải tự bấm qua từng cửa sổ
API key App không giữ, không đọc Tuỳ cách bạn tự quản lý
Voice hai chiều Có, tuỳ chọn bật/tắt Không có sẵn
Chi phí sử dụng Miễn phí (Orbit) + theo CLI/engine bạn chọn Như nhau — chỉ khác cách nhìn

Lưu ý: Orbit spawn CLI agent thật (Claude Code, Codex, Gemini…) — dữ liệu bạn gửi qua các CLI này tuân theo chính sách riêng của từng nhà cung cấp, Orbit không can thiệp hay lưu lại. Chỉ STT/TTS và engine Ollama chạy 100% cục bộ.
