## 1. Tóm tắt sản phẩm

Agent Console là web local đàm thoại **voice** điều phối nhiều CLI agent
(Claude Lead + Codex + Gemini): người dùng nói (hoặc gõ) → STT (faster-whisper)
→ **Lead** (Claude) đọc transcript chung, phát ra marker `[DELEGATE ...]` để
giao việc cho instance khác, hoặc `[SAY: ...]` khi đã có câu trả lời cuối,
hoặc `[ASK: ...]` khi cần hỏi lại người dùng → kết quả gộp vào **blackboard**
(transcript dùng chung, tự lưu `.jsonl`) → đọc trả lời bằng TTS (OmniVoice) +
hiện transcript trực tiếp trên trình duyệt.

Kiến trúc: FastAPI + WebSocket (`server/app.py`) phục vụ frontend tĩnh vanilla
JS (`web/`), gọi 3 CLI headless qua `subprocess` (`server/adapters.py`), điều
phối vòng lặp Lead qua `server/orchestrator.py`, cấu hình instance qua
`server/config.py` + `config.json`. Autonomy mặc định là mức `suggest` (chỉ
đọc/hỏi CLI, không cấp `full`) — đúng phạm vi Phase 1 (MVP), chưa có Agent
Library UI, quét folder/upload, PageIndex routing, session rename/resume UI,
remote toggle (dành cho Phase 2-4).
